# VARNOX PRIME XR — WhatsApp + Telegram Bot

Bot multi-session WhatsApp + Telegram (Baileys + Telegraf).

## Variables d'environnement requises

| Variable | Description |
|----------|-------------|
| `BOT_TOKEN` | Token Telegram obtenu via @BotFather |
| `STARTUP_PASSWORD` | Mot de passe démarrage (défaut: Varnoxornovark224) |

## Déploiement Railway

1. Importer ce repo sur [railway.app](https://railway.app)
2. Ajouter les variables d'environnement (`BOT_TOKEN`, `STARTUP_PASSWORD`)
3. Railway démarre automatiquement avec `railway.toml`

## Commandes disponibles

Préfixe `.` — ex: `.menu`, `.owner`, `.ping`, `.sticker`, etc.
